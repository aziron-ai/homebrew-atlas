## Install

```sh
brew install --cask aziron-ai/atlas/atlas
```

That single command taps this repository and installs the native `atlas`
binary for your platform (macOS and Linux, Intel and ARM). Downloads come
from the official [GitHub releases](https://github.com/aziron-ai/atlas/releases)
and are pinned by SHA-256 in the cask.

Then index a repository and go:

```sh
cd /path/to/repository
atlas index .
atlas search "checkout flow" --format plain   # where is it implemented?
atlas symbol CreateOrder                       # definition + callers + callees
atlas impact --paths services/cart.go          # what breaks if this changes?
```

## What the install does

Beyond placing the binary, the cask's post-install step:

- removes the macOS quarantine attribute from the downloaded binary, and
- runs `atlas bootstrap` to auto-register Atlas's MCP integrations with the
  coding assistants found on your machine — **Claude (desktop + CLI), Codex,
  Copilot, Cursor, and Gemini** — so they can query your index immediately.

From v0.1.47 the post-install step also sends **one anonymous install event**
to Google Analytics — channel (`brew`), version, OS, and arch only. No PII, no
machine identifier (a throwaway random `client_id`). Opt out by installing with
`ATLAS_NO_ANALYTICS=1` or `DO_NOT_TRACK=1`; the ping is best-effort (3-second
cap) and can never fail or slow the install.

Preview or repair registrations at any time:

```sh
atlas bootstrap --dry-run   # show what would be configured
atlas bootstrap             # (re)register assistant integrations
atlas doctor                # diagnose stale or broken registrations
```

## Upgrade / uninstall

```sh
brew upgrade --cask atlas
brew uninstall --cask atlas
```

After an upgrade, assistant registrations are automatically repointed at the
stable launcher. If an assistant ever fails to spawn Atlas after upgrading,
run `atlas bootstrap` once — `atlas doctor` shows which registrations are stale.

## About this tap

The [cask](Casks/atlas.rb) is generated by GoReleaser on every Atlas release —
version bumps land here automatically. Issues and feature requests belong on
the [main Atlas repository](https://github.com/aziron-ai/atlas/issues).
